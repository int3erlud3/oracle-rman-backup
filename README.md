A single, dependency-free Bash wrapper around **Oracle RMAN** for scheduled backups:
full (level 0), incremental (level 1), archivelog backups, retention maintenance,
corruption checks with `VALIDATE`, and restore readiness checks – with a lockfile,
per-run logs, a **dry-run that prints the exact RMAN script**, and
**Nagios/Icinga-style exit codes** for monitoring.

## Features

| Action | What it runs |
|---|---|
| `full` | `BACKUP INCREMENTAL LEVEL 0 DATABASE`, log switch, archivelogs not yet backed up, current controlfile and spfile |
| `incr` | same with `INCREMENTAL LEVEL 1` (differential, or `--cumulative`) |
| `arch` | log switch + `BACKUP ARCHIVELOG ALL NOT BACKED UP 1 TIMES` (optional `DELETE INPUT`) |
| `validate` | `BACKUP VALIDATE CHECK LOGICAL DATABASE ARCHIVELOG ALL` – physical and logical corruption check, nothing written |
| `restore-check` | `RESTORE SPFILE/CONTROLFILE/DATABASE VALIDATE` – proves the backups needed for a restore exist and are readable |
| `preview` | `RESTORE DATABASE PREVIEW SUMMARY` – which backups a restore would use |
| `maintenance` | `CROSSCHECK`, `LIST EXPIRED`, `REPORT OBSOLETE`; with `--delete` also `DELETE NOPROMPT EXPIRED/OBSOLETE` |

- Parallel disk channels (`--channels`), compression, multisection (`--section-size`),
  custom destination (`--dest`) and tags
- Retention as a **recovery window** (`--retention-days`, default 7) or **redundancy**,
  applied per command – the persistent `CONFIGURE` settings of the database are not changed
- Optional **recovery catalog** via a wallet alias (`CONNECT CATALOG /@alias`)
- `flock` lockfile per SID, timestamped log per run (directory `0700`, files `0600`),
  automatic pruning of its own old logs, optional `--max-runtime`
- `--check-syntax` runs `rman checksyntax` on the generated script
- One-line text status or JSON summary on stdout (error codes extracted from the log)

## Safe defaults

- **No passwords anywhere**: the target is connected with OS authentication
  (`CONNECT TARGET /`) as the Oracle software owner; a catalog only through a wallet
  alias. The RMAN script is passed via a private temporary `cmdfile`, never on the
  command line, and removed afterwards.
- **Refuses to run as root**; `TWO_TASK`/`LOCAL` are unset so the local SID is always
  the target; `PATH` is reset to `$ORACLE_HOME/bin:/usr/bin:/bin`.
- **Nothing is deleted by default**: `maintenance` only reports until `--delete` is given,
  archivelogs are kept unless `--delete-input` is given.
- **Strict input validation** (SID, tag, destination, numbers) – values are embedded in
  the RMAN script, so anything outside a safe character set is rejected.

## Installation

```bash
git clone https://github.com/int3erlud3/oracle-rman-backup.git
cd oracle-rman-backup
sudo make install                 # installs /usr/local/bin/oracle-rman-backup
```

Requirements: Bash 4.4+, util-linux (`flock`), coreutils, an Oracle home with `rman`.

## Usage

```bash
export ORACLE_SID=ORCL ORACLE_HOME=/u01/app/oracle/product/19.0.0/dbhome_1

oracle-rman-backup full --channels 2 --compress --dest /u02/backup/ORCL
oracle-rman-backup incr --cumulative
oracle-rman-backup arch --delete-input
oracle-rman-backup validate
oracle-rman-backup maintenance --retention-days 14           # report only
oracle-rman-backup maintenance --retention-days 14 --delete  # crosscheck + delete expired/obsolete
oracle-rman-backup restore-check --format json | jq .status

# show exactly what would run
oracle-rman-backup incr --channels 2 --compress --dest /u02/backup/ORCL --tag DAILY_INCR --dry-run
```

```text
# generated by oracle-rman-backup 1.0.0 - action incr, SID ORCL
CONNECT TARGET /
SET ECHO ON;
RUN {
  ALLOCATE CHANNEL d1 DEVICE TYPE DISK FORMAT '/u02/backup/ORCL/%d_%T_%U';
  ALLOCATE CHANNEL d2 DEVICE TYPE DISK FORMAT '/u02/backup/ORCL/%d_%T_%U';
  BACKUP AS COMPRESSED BACKUPSET INCREMENTAL LEVEL 1 DATABASE TAG 'DAILY_INCR';
  ALTER SYSTEM ARCHIVE LOG CURRENT;
  BACKUP AS COMPRESSED BACKUPSET ARCHIVELOG ALL NOT BACKED UP 1 TIMES TAG 'DAILY_INCR_ARC';
  BACKUP CURRENT CONTROLFILE TAG 'DAILY_INCR_CTL';
  BACKUP SPFILE TAG 'DAILY_INCR_SPF';
}
EXIT;
```

Status line (stdout) after a run:

```text
OK - full backup of ORCL completed in 1834s (tag FULL_20261008T010000), log: /u01/app/oracle/admin/ORCL/rman_logs/oracle-rman-backup_ORCL_full_20261008T010000.log
```

Run `oracle-rman-backup --help` for all options.

### Exit codes

| Code | Status | Meaning |
|---|---|---|
| 0 | OK | RMAN completed without errors |
| 1 | WARNING | completed with known warnings (e.g. `RMAN-08137` archivelog not deleted, objects that could not be deleted) |
| 2 | CRITICAL | RMAN failed (non-zero exit or `RMAN-00569` error stack), corrupt blocks found by `validate`, or `--max-runtime` exceeded |
| 3 | UNKNOWN | usage/configuration error, missing `rman`, lock held by another run |

### Logs

Default log directory: `$ORACLE_BASE/admin/$ORACLE_SID/rman_logs` (or `~/rman_logs`),
override with `--log-dir`. Each run writes the generated script and the complete RMAN
output (`msgno` enabled) to `oracle-rman-backup_<SID>_<action>_<timestamp>.log`.
Only files matching that pattern are pruned (`--log-keep-days`, default 30).

### Scheduling

See [`examples/`](examples) for a systemd template service + timer and a crontab.
The banner is printed to **stderr** only on interactive terminals (never under cron or
systemd, never with `--format json`); disable it with `--no-banner` or `NO_BANNER=1`.

## Testing

```bash
make lint test      # ShellCheck + bats
```

The bats suite (29 tests) runs against a **mock `rman`** ([`tests/mocks/rman`](tests/mocks/rman))
that records its arguments, environment and command file and replays canned RMAN output
(success, error stack, warnings, `VALIDATE` corruption) – no database required.
